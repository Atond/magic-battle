# Magic Battle

Jeu idle web 100 % statique : un magicien, des monstres, cinq écoles de magie, prestige et Ascension,
plusieurs jours de contenu. Sauvegarde locale, aucun compte. Joué sur https://atond.github.io/magic-battle/

Spec et cadrage : `docs/specs/projet/`. Porte de qualité : `npm run verify`.
